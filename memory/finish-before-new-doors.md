Nick, 2026-11-05 (Spiti session, after I planned a learning loop on top of an unfinished system): "before we build the
loop, we need to finish the whole system so we dont open new doors to inefficiency and this should be a rule. we need
to focus on one task at a time so we dont diverge. if i ask you something new or irrelevant you should suggest a new chat."

**Why:** half-built systems plus new ideas = drift and wasted time; he wants each system finished first.

**How to apply:** keep a short "left to finish" list for the current system and work it top to bottom, one item at a
time. New ideas (even good ones) go on a parked list, not into the plan. When Nick asks something new or unrelated to
the current task, say so in one line and offer a new chat (start_session offer) instead of doing it here.
