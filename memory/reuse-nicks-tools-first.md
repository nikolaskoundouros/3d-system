Nick, 14 Nov 2026, when I proposed rebuilding his clip analysis (1/6 s frames, Whisper, sound, captions):
"also if i already made it why do you want to redo it?"

**Why:** I had said "rebuild" only because the old tools (beats.py, hear.py, analyze.py) had moved when the Desktop
was archived. That wastes his earlier work and his time.

**How to apply:** when a task overlaps something he has done before, search first (old chats via transcript search,
~/Projects, ~/drive-holding, the Drive archives) and say where the existing tool is. If it is only in Drive, ask before
pulling it down. Propose building new only for the part that does not exist. Related: [[clip-analyzer]].
