Nick, 2026-11-06: "we discussed that if we have a problem, we find a solution instead of starting to work ... this was
a rule which was baked in no?" then "lets figure out why it slipped please so we can fix it".

What slipped: the 12:30 rule (research and remake the missing capability first) was written in memory and decisions.md,
not in learn/BRIEF.md (what learners read) and not as a gate; my order to the main chat paraphrased it ("help clear the
head bottleneck"), the main chat paraphrased again, and the learner built its own head. I relayed its 13:05 report
("sculpting his old man's head first") without checking it against the rule. Same shape as the checker's random mode
(the judged side loosened the judge) and gold's traced pass.

**Why:** prose rules in files nobody reads at decision time are wishes; relays lose precision per hop; reports are
claims.

**How to apply:**
1. A rule counts as in place only when (a) it is in the file the actor reads (BRIEF.md for learners, the checker for
   passes, the queue for starts) and (b) something mechanical enforces it (a needs field, a grant file, a test case).
   Until then say "rule written, not yet enforced".
2. Orders to other sessions carry the rule text verbatim plus the exact action per item; no paraphrase.
3. Every report from a session is checked against the current rules and the pictures before it is relayed to Nick.
4. A blocked remake's learner is told "stop" in that word, never "help".
